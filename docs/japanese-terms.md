# 日本語の用語の使い分け

日本語の文書で、ソフトの種類（サービス・アプリ・ツール・スクリプト）と作業の区切りを呼ぶ言葉を定めます。
人や生成AIが、同じものを文書ごとに違う言葉で呼ばないようにし、英語の言葉を直訳した言い方を避けるための規約です。

## 1. 位置付けと適用範囲

- 本書は、人と生成AIが書く日本語の文書（README・SKILL.md・CHANGELOG・docs・規約、スライドや動画の文）に適用します。
- コード・識別子・設定キー・製品やツールの正式な名前（`tools` の項目、application ID、Claude Codeの「Agent」ツールなど）は、そのまま書きます。本書の言葉に言い換えません。
- CHANGELOGの前の項目や作業の記録は、書いた時点の言い方のまま残します。言い方を変えたときは、読み替えを新しい項目に書きます。
- 対象リポジトリの指示や仕様に別の決まりがあれば、そちらに従います。

## 2. ソフトの呼び方

同じ製品でも、どの面を言うかで呼び方が変わります。
ネットワークの向こうの契約やアカウントを言うならサービス、PCやスマホで開く画面を言うならアプリ、コマンドで動かすものを言うならCLI（ツール）、作業を任せる相手を言うならAIエージェントです。

### 2.1. サービス

- 指すもの：ネットワークの向こうで動き、アカウント・契約・APIを通じて使うもの。
  - 例：GitHub、ChatGPT、claude.ai、OpenAIのAPI、YouTube、Microsoft 365・SharePoint、Azure。
- 指さないもの：
  - 同じ製品の、PCやスマホで開く画面は「アプリ」と書きます（2.2）。ブラウザーで開く画面は「Web版」「Webの画面」と書きます（例：ChatGPTのアプリ、GitHubのWebの画面）。
  - Windowsで常駐して動くプログラム（`services.msc` に並ぶもの）は、必ず「Windowsのサービス」と書きます。
- 例文：
  - 「レビューでは、差分がCodex CLIを通じてOpenAIのサービスへ送られます。」
  - 「取得の前に、サービスの利用規約と権利を確かめます。」

### 2.2. アプリ

- 指すもの：画面があり、人が開いて操作するソフト。
  - 例：PowerPoint・Excel（デスクトップ版）、Obsidian、ブラウザー、Claude・ChatGPT・GitHub Copilotのデスクトップアプリ、スマホのアプリ。
  - スクリプトがCOMなどで外から動かすときも、PowerPointはアプリです。
- 指さないもの：
  - 画面がなく、コマンドで動かすもの（ffmpeg、git、`tkn-excel-note`）。「CLI」と書きます（2.3）。
  - 「アプリケーション」という長い形は、説明文では使いません。[Python CLI開発基本方針](python-cli-development.md) は、インストールして使うCLIを設計するときの言葉（Pythonアプリケーション、application ID、application directory）として使います。
- Windowsの設定画面の「アプリ」：画面の名前として、「アプリ」>「インストールされているアプリ」のように書きます。そこにCLIが並んでいても、文書ではCLIと呼びます。
- 例文：
  - 「デスクトップ版のPowerPointが要ります（アプリ。WindowsのCOMで動かします）。」
  - 「GitHub Copilotのアプリも、CLIと同じSkillのフォルダを読みます。」

### 2.3. ツール

- 指すもの（2つ）：
  1. AIエージェントが呼ぶ機能。組み込みのツール（ファイルを読む・書く、シェル、Web検索など）、Botの定義で許すツール、コネクタ（MCPサーバー）が足すツール、ほかのエージェントを起動するツール。
  2. PCに入れて、名前で呼んで使うものの総称。ffmpeg、git、rg、uv、markdownlint、Mermaid CLI、yt-dlp、自作の `tkn-excel-note` など。
- 書き分け：
  - 1と2が紛れるときは、1に持ち主をつけます（「組み込みのツール」「Botのツール」「コネクタのツール」）。
  - 2は、形が分かれば「CLI」「アプリ」「ブラウザー」と具体的に書きます。「ツール」は、種類の混ざった集まり（「ツール（npm・uv・Playwright・ffmpeg・Python）」）や、役割で呼ぶとき（「取得のツール（例：yt-dlp）」）に使います。
  - 自作のものも、入れて名前で呼ぶならツール（CLI）です。中身がPythonでも、スクリプトとは呼びません（2.4）。
- 指さないもの：
  - AIエージェントそのもの（Claude Code・Codex・GitHub Copilot）。「AIエージェント」と書きます（2.5）。中の機能（1）と紛れるためです。
  - コネクタ・MCPサーバーそのもの。「コネクタ」と書き、それが足す機能をツールと呼びます。
  - リポジトリやSkillにファイルとして置いたコード。「スクリプト」と書きます（2.4）。
  - `.venv/`・`node_modules/` に入るもの。「パッケージ」と書きます（2.5）。
- 例文：
  - 「Botが使えるツールを、定義の `tools` に書いたものだけにします。」
  - 「CLIとして配られているツール（Mermaid CLIなど）を呼ぶだけなら、どの言語からでも呼べます。」

### 2.4. スクリプト

- 指すもの：リポジトリ・Skill・制作フォルダにファイルとして置き、パスを指して動かすコード。写したり、直したりします。
  - 例：Skillの `scripts/` のPython、動画の制作フォルダの書き出しのスクリプト（`render.mjs`）、`uv run <名前>.py` で動かす1ファイル、PowerShell・AutoHotkey・BATのファイル。
- 指さないもの：
  - 入れて名前で呼ぶもの。「CLI」「ツール」と書きます（2.3）。
  - Excel・WordなどOfficeの中のVBA。「マクロ」と書きます。
- 境目：スクリプトをCLIに移す条件は、[Python CLI開発基本方針](python-cli-development.md) の2.2に従います。パスを指して動かすうちはスクリプトで、入れて名前で呼ぶようになったらCLI（ツール）です。引数を受け取るスクリプトでも、入れていなければCLIとは呼びません。
- 例文：
  - 「前の動画からスクリプトを写し、前の動画に固有の値を直します。」
  - 「SkillにはPythonのスクリプトが入っているので、URLを渡すだけでは使えません。」

### 2.5. 隣の言葉

- AIエージェント：作業を任せる相手（Claude Code・Codex・GitHub Copilotなど）。
  - 形を言うときだけ、「Claude Codeのデスクトップアプリ」「Codex CLI」「GitHub Copilotのアプリ」と書きます。
  - シーケンス図などで、推論する側を短く言うときは「AI」と書いてもかまいません。
  - 「ツール」「アプリ」「生成AIのツール」とは呼びません。
- CLI・コマンド：CLIは、コマンドで動かすツールの形です。コマンドは、打ち込む1行やサブコマンド（`tkn-excel-note config list`）を指します。
- パッケージ・ライブラリ：`.venv/`・`node_modules/` に入れるもの（numpy、openpyxl、Playwrightなど）は、入れる・版を固定する話では「パッケージ」、コードから呼ぶ話では「ライブラリ」と書きます。
- コネクタ：AIエージェントにサービスをつなぐもの（MCPサーバー）。コネクタが足す機能は、ツールと呼びます（「コネクタのツールが残る」）。
- Skill・Bot：AIエージェントに渡す定義（手順・役割）です。サービス・アプリ・ツール・スクリプトのどれにも当たりません。Skillの中に、スクリプトが入っていることはあります。

### 2.6. 境目の例

| もの | 呼び方 | 理由 |
| --- | --- | --- |
| Claude Code・Codex・GitHub Copilot | AIエージェント | 「ツール」と呼ぶと、中の機能と紛れる。「アプリ」は、デスクトップで開く形だけを指す |
| GitHub・ChatGPT | サービス。画面を言うときはアプリ・Web版 | 同じ製品でも、どの面を言うかで呼び方が変わる |
| 自作のCLI（`tkn-excel-note`） | CLI・ツール | 入れて名前で呼ぶ。画面がないので、アプリではない |
| Skillの `scripts/` のPython | スクリプト | パスを指して動かし、写して直す。引数を受け取っても、入れていなければCLIと呼ばない |
| Windowsの設定画面の「アプリ」 | 画面の名前として「」で書く | 設定画面はCLIも並べるので、本書のアプリより広い |
| AIエージェントの組み込みのツール | ツール（組み込みのツール） | AIエージェントが呼ぶ機能 |
| MCPのコネクタ | コネクタ。足す機能がツール | コネクタは機能を足す側で、機能そのものではない |
| Chromium（Playwrightで入れる） | ブラウザー（アプリ） | Playwrightは、パッケージ（ブラウザーを入れるCLIも持つ） |
| Python | 言語の名前で書く。ツールの集まりに入れてもよい | 処理系を入れる話では、ffmpegなどと並べて書ける |
| Excel・WordのVBA | マクロ | Officeの中で動き、ファイルとしてパスを指して動かさない |

## 3. 作業の区切り：工程と処理

- 作業の大きな区切りは「工程」と呼びます。番号を付けるときは「工程1〜4」のように書きます。
  - 例：「原案からシナリオを作り、絵コンテで形を確かめます（工程1・2）。」
- 1つの工程や仕組みの中で、データを流す1つずつの手順は「処理」と呼びます。
  - 例：「書き出しは、時刻ごとに撮る処理と、ffmpegでつなぐ処理に分かれます。」
- 「段」（段1・段2）とは呼びません。

## 4. 英語の直訳を避ける

英語の言葉を1語ずつ置き換えた言い方は、日本語の説明文で普通使わないため、使いません。

| 英語 | 使わない言い方 | 使う言い方 |
| --- | --- | --- |
| tool（AIエージェントの機能、入れて使うもの） | 道具 | ツール（2.3） |
| script | 道具 | スクリプト（2.4） |
| step・stage（作業の大きな区切り） | 段 | 工程（3章） |
| step（データを流す中の1つずつ） | 段 | 処理（3章） |

新しい言葉を当てる前に、日本語の技術文書で普通使う言い方かを確かめます。
迷うときは、候補を例文つきで並べてから決めます。
